# 剧本场景速查

| 场景 | 用户说法示例 | 优先平台 | 高风险 |
|------|--------------|----------|--------|
| 主机隔离 | 隔离这台主机、EDR quarantine | octomation / w5 | 是 |
| 账号禁用 | 锁定该用户、强制下线 | 身份类剧本 | 是 |
| IP 封禁 | 封 1.2.3.4、加黑名单 | 网络设备 / WAF | 是 |
| 邮件召回 | 召回钓鱼邮件 | 邮件网关 | 中 |
| 云密钥吊销 | 禁用 access key | 云厂商 | 是 |
| 日志采集 | 拉主机日志/快照 | 取证类 | 否（只读优先） |
| 验证恢复 | 确认已解封、恢复访问 | 对应回滚剧本 | 中 |

执行前确认：目标标识、影响范围、是否可回滚、是否需 HITL。
