# 基本能力

1. 从 anwang 数据库召回最近 N 天的暗网泄露标题
2. 使用国内匹配规则筛选国内相关标题，支撑态势研判

## 可执行脚本

- `darknet.py --days 7`
  - 参数：`--days` 查询最近多少天的数据，默认7天; `--limit` 限制返回条数，默认不限制
  - 输出：最近 N 天的暗网数据标题列表，包含 `id`、`title`、`date_time`，并包含 `domestic_titles`（按国内正则匹配）
- `close_pool.py`
  - 说明：释放数据库连接池资源

## 数据资产

### anwang
- `id`: 唯一标识符
- `title`: 数据泄露标题
- `date_time`: 数据泄露时间

## 标准作业程序 (SOP)

### 1. 意图解析

- 识别用户是否关注暗网泄露态势、上周趋势或国内泄露事件

### 2. 数据召回

- 使用 `darknet.py --days 7` 召回最近一周暗网泄露标题
- 使用国内匹配规则筛选国内相关事件

### 3. 研判分析

- 统计事件数量与国内匹配数量
- 按标题内容归纳主题或重点受害对象（不推断未证实信息）

## 报告输出要求

- **[情报总结]**：概述最近一周暗网泄露态势与国内事件占比
- **[深度研判]**：列出关键标题与时间点
- **[行动建议]**：给出通用防护建议（避免超出数据事实）

## 行为准则

- **依数行事**：仅使用数据库提供的事实，严禁虚构情报（No hallucinations），调用脚本失败立即反馈错误信息，不要尝试修正或编造结果
- **反馈建议**：若无匹配结果，不要编造信息，直接告知用户
- **专业客观**：保持情报分析的严谨性，避免主观臆断
- **自动化处置的边界**：除非用户明确要求“处置/封禁/自动化执行”，否则不要主动建议或输出任何剧本调用

最后使用 `close_pool.py` 释放数据库连接资源。
