# HITL 模拟处置

仅当用户明确要求对指定资产进行模拟隔离或模拟封禁时，调用 `hitl_simulate_containment`。如果该工具在当前 MCP 能力中不可用，明确说明无法发起审批，不要改用其他处置工具。

## 调用前

确认目标、动作（`isolate` 或 `block`）和理由。可简要说明：该工具会暂停运行并等待管理员在审批中心处理；在工具返回前不要声称处置已生效。

## 调用后（以工具返回 / 错误信息为准）

工具返回后，必须根据返回结果汇报最终状态，不要再写“等待管理员审批”。

- `status=simulated`：管理员已审批通过，模拟处置已记录；说明外部系统未发生实际变更。
- 工具错误 / 拒绝信息（例如包含 `Rejected by administrator`）：明确说明**未执行**模拟处置，并**完整转述管理员拒绝原因**，不得只写“审批被拒绝”。
- 工具未返回或调用失败：说明审批/执行未完成及原因。

不要调用真实外部处置系统。
